# 下载与上手

这一页写给想直接使用小丑鱼的人：不需要装 Node.js，也不需要看代码。想从源码运行或参与开发，请看[快速开始](getting-started.md)。

## 1. 下载

到 [GitHub 发布页](https://github.com/mmlong818/nemos/releases) 下载最新版本里的 `Clownfish-版本号-windows-x64-portable.zip`（Clownfish 是小丑鱼的英文名）。目前只提供 Windows 64 位版本。

压缩包大约 170 MB，里面已经带好运行所需的一切。

## 2. 解压并打开

1. 右键压缩包 → **全部解压缩**，放到一个你找得到的位置，比如 `D:\小丑鱼`。不要在压缩软件里直接双击运行，那样程序找不到自己的文件。
2. 打开解压出来的文件夹，双击 **小丑鱼.exe**。

第一次打开时，Windows 可能提示“Windows 已保护你的电脑”。这是因为程序还没有代码签名，不代表检测到了问题。点 **更多信息 → 仍要运行** 即可，之后不会再提示。

## 3. 第一次使用

1. 告诉小丑鱼怎么称呼你。
2. 连接一个模型服务。没连之前，小丑鱼只能给出几条固定建议，输入框上方会一直提示“还没有连接模型”，点 **去连接** 即可。

在 **设置 → 模型与服务 → 服务账号** 填一个 Key，点 **保存并完成配置**：

| 服务 | 适合 | 去哪申请 |
| --- | --- | --- |
| 智谱 BigModel | 国内网络可直接使用，中文对话与任务 | [智谱开放平台](https://bigmodel.cn/usercenter/proj-mgmt/apikeys) |
| OpenAI | 文字、看图、语音、图像能力最全 | [OpenAI 平台](https://platform.openai.com/api-keys)（国内通常需要代理） |

填一个就能用，两个都填会互为补充。保存时会各发一次很小的验证请求，可能产生少量费用。模型调用按各服务商的价格从你自己的账户扣费，小丑鱼本身不收费。

用 Anthropic、DeepSeek、通义千问或其他兼容服务，点同一页的 **+ 添加其他服务**。

## 4. 你的数据在哪里

- 对话、记忆、事项、文件和设置都保存在这台电脑的 `C:\Users\你的用户名\.clownfish`，不在程序文件夹里。
- Key 用当前 Windows 账户加密保存，拷到别的电脑也解不开。
- 只有你使用模型、联网搜索、插件或同步时，必要的内容才会发送给对应的服务。完整说明见[隐私协议](../PRIVACY.md)。

## 5. 更新

第一次打开后，左下角会问你“有新版本时提醒你？”。选 **提醒我** 后，小丑鱼每 12 小时最多向 GitHub 读取一次最新版本号，不发送任何个人数据；随时可以在 **设置 → 数据与隐私 → 检查新版本** 关掉。

有新版本时左下角会出现 **新版本 x.y.z 可以更新**。更新方法：

1. 在托盘图标上右键退出小丑鱼。
2. 下载新的压缩包，删掉旧的程序文件夹，把新的解压到原来的位置。

数据在 `.clownfish` 里，换程序不会丢失对话、记忆和设置。

## 6. 卸载

退出小丑鱼后删除程序文件夹即可。想连数据一起删除，再删掉 `C:\Users\你的用户名\.clownfish`，这一步无法恢复。如果开启过“开机自动启动”，先在托盘菜单里取消勾选。

## 7. 常见问题

**提示“API Key 无效或未被服务接受（HTTP 401）”**：Key 复制得不完整，或已经在服务商后台被删除。回到服务商后台重新复制完整的 Key 再粘贴。

**提示“服务额度不足或请求过于频繁（HTTP 429）”**：账户余额用完或请求太快。检查服务商账户余额，或稍后再试。

**OpenAI 一直连不上**：国内网络通常无法直接访问 OpenAI。可以改用智谱，或在 **设置 → 模型与服务 → 高级** 里配置代理。

**关掉窗口后程序还在**：小丑鱼会缩到右下角托盘继续运行，以便按时提醒。要彻底退出，在托盘图标上右键选择退出。

## 8. 反馈问题

左下角的 **反馈问题** 会打开 [GitHub Issues](https://github.com/mmlong818/nemos/issues/new/choose)。请写上左下角显示的版本号、你做了什么、看到了什么。**不要在 Issue 里贴 API Key、对话内容或其他个人信息。** 安全问题请按 [SECURITY.md](../SECURITY.md) 私下报告。
