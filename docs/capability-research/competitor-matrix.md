# 同类产品能力矩阵

更新：2026-08-13

## 比较结论

| 产品 | 核心优势 | 小丑鱼可学习 | 不应照搬 |
|---|---|---|---|
| 腾讯 WorkBuddy | 本地执行环境、Office/WPS 原位编辑、技能市场、专家包、连接器推荐、办公与开发统一 | 免配置工具链、技能生命周期、原位编辑的能力探测与回退、厚领域包 | 腾讯服务绑定、把专家和插件复杂度暴露给新手 |
| Claude Cowork | 选择文件夹后执行长时多步知识工作；本地文件、桌面应用和连接器形成上下文闭环 | 文件夹授权、长任务监督、连接器与技能分工、网络和文件代理策略 | 对单一云模型和订阅体系的强依赖 |
| OpenAI Codex | 多任务线程、隔离工作树、差异审阅、技能、自动化和后台审阅队列 | 开发项目工作台、并行隔离、统一审阅、技能自动匹配 | 面向开发者的术语和操作负担 |
| Microsoft 365 Copilot | 在 Word、Excel、PowerPoint 内原位执行；内容保持可编辑；使用组织上下文 | 原位编辑、修改预览、模板与品牌继承、跨应用一致入口 | Microsoft 365 与 Graph 的封闭依赖 |
| Genspark / GenOffice | 面向普通用户直接生成文档、表格、演示等完成品 | 成果优先的入口、生成后继续编辑、统一办公套件体验 | 只追求生成速度而弱化来源和可审计性 |
| Manus | 沙箱化长任务、研究、网页和数据产物、交付结果页面 | 任务计划、过程证据、可分享成果、验证代理 | 云端黑盒执行和信用点式复杂计费体验 |
| OpenClaw 类产品 | 消息渠道、庞大技能生态、长期运行和远程触发 | 可选的远程触发、技能兼容层、后台任务 | 默认获得广泛系统权限、未经审查的技能供应链 |

## 研究后的产品方向

小丑鱼应定位为“有记忆、可监督、面向普通人的本地工作代理”。它不需要成为另一个插件商店，也不需要把运行细节变成主界面。用户只需要新建任务、交付材料、查看过程、审阅成果和继续修改。
