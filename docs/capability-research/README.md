# 小丑鱼能力提升研究区

更新：2026-08-13

本目录用于独立收集小丑鱼尚欠缺的能力、同类产品证据和可落地方案，不在研究阶段直接修改主产品代码。

## 工作原则

1. 菜单、宣传文案和预留接口不算能力；只有真实执行路径和可核验产物才算。
2. 每项结论区分：官方声明、安装包证据、源码证据、实际验证。
3. 不照搬品牌、角色、提示词或受保护素材，只提炼通用工作流与工程方案。
4. 先补高频闭环，再扩充能力数量。
5. 所有候选能力必须说明依赖、权限、失败方式、人工确认点和验收样例。

## 文件

- `improvement-plan.md`：分阶段提升计划和验收标准。
- `competitor-matrix.md`：同类产品的能力比较与可学习内容。
- `capability-backlog.md`：能力缺口、优先级和进入开发的条件。
- `evidence-register.md`：证据来源、可信等级和待验证事项。
- `feishu-document-model.md`：飞书“原文件保留、转换后编辑”模式及小丑鱼方案。

## 当前判断

小丑鱼的记忆、安全边界和任务数据结构已经具备竞争力；主要短板是原位办公编辑、完整开发工作台、现成连接器、领域能力包和免配置运行环境。当前重点不是再增加入口，而是把已有入口变成可持续交付成果的闭环。
