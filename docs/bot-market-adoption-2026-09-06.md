## 数据与执行保障

- 目录是随应用发布的本地白名单，无第三方在线发布、自动更新或任意 URL 导入。
- `GET /api/assistant-team/market` 只读，不添加 Bot，不调用模型。
- `POST /api/assistant-team/import` 接受模板 ID 与数值版本；查找服务器内置模板，忽略客户端提供的规则、身份或权限覆盖。未知 ID 返回 404，版本不符返回 409。
- 数据存入已有 `assistant-bots.db`，以当前用户隔离；每种模板生成一个独立实例 ID，事务内检查、添加。重复添加返回现有实例，不增加副本、不恢复已停用实例、不覆盖个人编辑。
- 继承最多 40 个 Bot 的上限；上限不阻止重新获取已添加模板。编辑保存时来源不可伪造、替换或删除；普通自建 Bot 不能冒充市场来源。
- 添加操作经过现有用户动作审计，不启动后台任务，不读取私人记忆、不存入推断的用户事实。
- 执行使用既有协作队列、启动时规则快照、任务级材料、工具关闭和空 memory scopes。材料会发送至用户配置的模型服务；模板来源、示例等不随任务自动发送。
- 角色输出和最终汇总依赖模型质量。必填字段检查只保证结构，不保证事实正确，也不证明外部动作已完成。
- 后续目录若升级，现有个人版本不自动覆盖；此版本尚无模板升级、卸载、第三方发布或插件依赖安装流程。

## 本轮验证

自动化新增 7 项测试：

1. 三个来源、边界、示例标记、指纹格式及目录副本隔离。
2. 添加幂等、用户隔离、版本校验、保护停用/编辑版本、防伪造来源。
3. 40 个 Bot 上限及已有导入重试。
4. 三个模板分别进入真实协作运行器，由模拟模型返回工作成果和最终字段；检查工具关闭、空记忆范围、共享材料一致。
5. HTTP 测试无需模型即可浏览/添加、五次并发添加不重复、不产生模型调用或任务、错误版本与请求体拒绝、编辑后重启持久化。

`npm run typecheck`、前端 `node --check` 通过；全量 `npm test`：489 项，488 通过，0 失败，1 项既有跳过。
