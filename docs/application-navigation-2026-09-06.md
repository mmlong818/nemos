## 修复内容

- 各页入口数量、顺序和当前页高亮不一致。
- 项目、资料、成果、任务记录等 URL 被客户端强制显示成自动化。
- 工作分区缺少可见导航与明确标题。
- 工作分区、Bot 标签页切换后，浏览器前进/后退未正确恢复页面。
- 侧栏新建按钮职责不清、重复绑定导致自动化被重置为手动任务；资料与项目现在打开各自表单。
- 任务表单关闭后再次打开，访问已移除时间输入框可能报错。
- 固定导航切换页面时挤压主区域，以及窄窗口旧布局覆盖导致侧栏挡住正文。
- Bot、事项与其他页面的壁纸加载、侧栏视觉和重点色不一致；保留用户原有壁纸偏好。
