# 任务入口的执行技能建议与转交

## 本轮实现

- 目标输入时，以明确关键词从现有 11 项白名单执行技能中建议最多 3 项。仅用于候选入口，不宣称语义规划、工具就绪或多技能串行执行。
- 例如“制作一份 PPT”显示演示制作准备入口；负向要求和单纯“审阅 PPT”不会被当成制作请求。
- 用户点击后在新窗口打开原技能准备页，带入目标、补充文字及交付要求；不点击或调用开始执行，不调用模型，不提取附件。
- 原任务窗口保留草稿与 File 对象，附件需在准备页重新选择；可见提示明确说明该限制。
- 新准备页默认关闭偏好记忆；模型与工具仍需按执行页确认，不默默假装继承原任务的所有设置。
- 临时文字通过同源新窗口复制的 sessionStorage 转交，不放进 URL 或服务器。令牌单次读取，验证技能 ID、格式、16000 字限制与十分钟有效期；原窗口创建后清理令牌，子窗口读取后清理令牌并移除 URL 参数。子窗口的 opener 立即断开。
- 弹窗被阻止、存储不可用、内容超长、令牌过期或目标页面非空时明确报错，不截断或覆盖输入。

## 验证

- 136 项相关测试通过，0 失败；类型检查通过。本轮新增 4 项建议、数据转交、安全校验与无执行副作用测试。
- 独立 Edge 浏览器实际确认：目标、合成补充说明与交付要求完整带入；原任务附件仍在；偏好记忆关闭；opener 断开；临时数据已清理。
- 实际模拟 window.open 返回空值：提示允许弹窗后重试，原草稿、附件保留，待处理令牌数量为 0。
- 桌面 1440×1000 及小屏 390×844 的按钮路径检查。截图保存于 outputs/skills-migration-20260907/task-skill-suggestion.png 与 transferred-preparation.png。
- 没有付费模型调用、真实任务提交、用户数据改写或服务重启。
