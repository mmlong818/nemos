## 合入范围

- **直接适配**：重连策略的五条件判断函数（Apache-2.0）。新增轻量 SSE
  适配，不复制上游 WebSocket 协议或运行时。首次连接、重连都重新读取持久
  状态；合并事件刷新；保留原生 EventSource 退避；终态只允许显式重连；
  页面离开、返回与旧连接的迟到事件都有生命周期保护。
- **按机制重写**：关系记忆区分文件不存在、正常与读取异常。损坏/结构错误
  不再当成空档案，阻止相关读取及覆盖；写盘成功前不更新内存；检查外部
  文件变化。这里保护的是 `counterparts.json`，不是替换 `nemos-memory`。
- **按机制重写**：现有审阅队列扩展为稳定来源 ID 的待处理事项，优先显示
  结果不确定的任务，然后是审批、失败/中断、等待送达。相同运行的审批分组，
  但每个具体操作仍须分别决定。不将“已送达”冒充“用户已读”。
- **界面接入**：自动化页显示待处理入口；运行记录可定位与处理；修复记忆/
  运行记录路由误落入自动化页。沿用既有样式，不改导航主结构。

没有采用记忆图界面、Rust 工作流执行器、AI 编程引擎或协作服务端。
没有新增 npm 运行依赖。Apache 许可、上游提交和本地修改记录保存在
`sdk/typescript/examples/companion/vendor/buzz/`，随现有便携构建规则复制。
