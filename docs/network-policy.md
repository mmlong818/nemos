# 出站网络策略

小丑鱼对应用自身发起的网页读取提供按主机名配置的出站策略。规则优先级为 `deny > allow > defaultAction`；拒绝在 DNS 解析前生效，避免对被拒绝目标泄露解析意图。

主机模式只接受精确域名、IPv4 字面量或 `*.example.com` 形式的子域通配。协议、端口、路径与 IPv6 字面量不作为策略模式接受；无效规则会报错，不会静默忽略。`*.example.com` 不匹配裸域 `example.com`。

策略通过 `GET /api/network-policy` 读取，通过 `POST /api/network-policy` 校验并原子保存。配置损坏时接口会返回加载错误，运行时采用默认策略，避免一份坏文件让全部网页读取无提示失效。

这项策略只约束应用自身的网页读取。由 MCP 扩展启动的子进程受各自的扩展沙箱、权限声明和用户批准约束，不应把主机策略理解为覆盖整个操作系统的防火墙。

扩展沙箱支持 Node 权限模型与 Windows AppContainer。无法在沙箱中运行且会启动本机进程的扩展必须向用户说明文件和网络边界，并取得明确允许；产品不得把浏览器自身的进程隔离表述成扩展沙箱。
