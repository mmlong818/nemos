# 个人事项、显式学习和客户端候选包

日期：2026-09-06。目标是个人长期助理，不恢复已移除的开发引擎。

## 本批实现

1. `/matters`：目标、下一步、等待条件、截止/跟进时间、任务与交付关联、完成结果；单独 SQLite 持久化，用户隔离和 revision 冲突保护。
2. 后台提醒：应用运行时生成到期提醒，重启补查、去重、确认不重复；不自动发送、购买或执行外部任务。
3. 学习候选：偏好、决定、约束先待确认，只有明确确认才写入 nemos-memory 核心；可检查来源、拒绝、撤回；中断回执按稳定提议 ID 恢复，避免重复写入。不承诺跨多个同时运行的进程的分布式恰好一次。
4. 助理工具：可读取/更新事项、提出学习；没有自动确认学习的模型工具。关闭记忆上下文时不提供此组工具。
5. Windows 客户端：后台轮询匿名化的提醒摘要、通知去重、唤醒后重查、所属后端退出后恢复；异常退避。不会在锁屏通知中暴露事项标题。真实物理唤醒与通知交互仍待验收。
6. 独立候选输出目录，拒绝覆盖同名发布目录；编译失败立即中止。包内 Node 直接载入 tsx，避免多余启动包装进程；退出时等待所属后端终止。
