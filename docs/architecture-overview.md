# Nemos Memory SDK 架构总览

状态：消费 `@nemos/sdk` 0.7.5-alpha.18
更新：2026-08-13

## 1. 定位

Nemos 是嵌入式 TypeScript 长期记忆引擎，源码在独立的 `nemos-memory` 仓库维护；本仓库只通过固定依赖版本消费它。它不是托管账号系统、通用向量数据库或完整 Agent 编排框架。

小丑鱼是它的首个完整应用。

## 2. 实例和隔离

应用创建一个 Nemos 实例，再通过 **forUser(userId)** 获取用户视图。

~~~text
Nemos tenant
  ├─ user:A
  ├─ user:B
  └─ persona:role-id
~~~

tenantId 与 userId 共同构成存储边界。服务端应用必须从可信身份映射 userId。

## 3. 记忆层

| 层 | 用途 | 典型来源 |
|---|---|---|
| archival | 不可变原始事件 | 用户原话、导入文本 |
| episodic | 经历和事件 | 对话、会议、任务进展 |
| semantic | 一般稳定事实 | 文档和事件抽取 |
| personal_semantic | 关于用户的稳定信息 | 偏好、关系、个人状态 |
| procedural | 可复用做法 | 工作习惯、流程和策略 |

原始事件与派生记忆分开。派生内容不能伪装成用户明确陈述。

## 4. 写入生命周期

~~~text
输入
  → 原始 archival 提交
  → 抽取与规范化
  → 结构化 claim
  → 证据和来源关联
  → 冲突、纠正或失效
  → 可召回状态
~~~

同步与后台写入共享持久生命周期。失败会保留阶段和错误，不把只写入原文描述为完整抽取成功。

## 5. 事实演化

结构化事实通过主体、谓词和对象形成 claim：

- 新值可以替代旧值；
- 事件时间决定事实何时有效；
- 同时同可信度的冲突可以进入争议状态；
- 纠正与失效保留审计关系；
- 历史版本仍可用于明确的历史查询。

## 6. 召回

召回先生成轻量查询计划，再组合多个通道：

- 当前结构化事实；
- 关键词全文检索；
- 实体与关系；
- 时间范围；
- 可选向量；
- 有界原始证据回退。

结果是结构化 MemoryPacket，包含记忆、选择原因、来源覆盖、预算和可靠性信息。弱证据不会为了凑数量强行进入结果。

## 7. 长期保留

每条记忆可以包含：

- salience 长期重要性；
- evidence coverage；
- evidence count；
- 访问与衰减状态；
- 敏感标记；
- belief state；
- valid / invalid 时间。

反思、失效和领域路由是可配置能力。小丑鱼当前开启反思、失效和质心领域路由。

## 8. 存储

当前公开存储：

- SQLite：持久化、本机使用；
- Memory：测试和临时进程。

SQLite 包含全文检索；向量能力取决于配置的 embedding provider 和本机扩展可用性。

## 9. 小丑鱼中的使用

- 用户消息写入用户命名空间；
- 角色回复写入角色命名空间；
- 普通对话召回相关记忆；
- 能力可以只召回交付偏好；
- 记忆页允许添加和忘记分类记忆；
- archival 在普通界面受保护。
