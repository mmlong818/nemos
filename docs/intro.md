# 小丑鱼与 Nemos

更新：2026-08-13

## 两个层次

**小丑鱼**是用户直接使用的本机 AI 应用，提供聊天、能力、办公文件、任务、工作空间、结果、运行和记忆管理。

**Nemos Memory SDK** 是独立仓库 `mmlong818/nemos-memory` 维护的 TypeScript 长期记忆内核。本仓库按固定 tag 引入 `@nemos/sdk`，不再保留第二份内核源码。

两者关系：

~~~text
小丑鱼界面
  ├─ 聊天与角色
  ├─ 能力与文件
  ├─ 可选的工作空间，以及可继续、可版本化的任务、运行和结果
  └─ 记忆管理
          ↓
Nemos Memory SDK
  ├─ 用户隔离
  ├─ 原始归档与分类记忆
  ├─ 事实演化与失效
  ├─ 相关、时间和证据召回
  └─ SQLite / 内存存储
~~~

## 当前可用

- TypeScript 嵌入式 SDK；
- SQLite 与内存存储；
- 五类记忆层；
- 同步和后台写入；
- 结构化事实、纠正、失效和争议处理；
- 时间、关键词、实体和向量召回；
- 召回原因与可靠性信息；
- JSON-LD 与 Markdown 导出；
- 小丑鱼本机应用和 Windows 便携客户端。
- 对话、能力和文件之间的任务来源、结果版本与恢复入口。
- 按需创建的工作空间，用于归类同一件事下的多个任务和结果。

## 数据边界

小丑鱼默认把数据放在本机。使用外部模型时，当前请求和必要上下文会发送给用户配置的模型服务商；使用联网来源时会访问相应网络服务。

记忆 SDK 不提供登录、账号、配额或计费。集成方必须从可信服务端身份得到 userId，并在应用边界完成授权。
