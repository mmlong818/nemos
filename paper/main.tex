\begin{abstract}
Persistent memory layers for LLM agents are typically evaluated on \emph{recall}:
can the system retrieve what was said earlier? We argue that in long-lived use the
dominant failure modes are not recall but \emph{maintenance}: (1) failing to revise a
belief when a fact changes, (2) letting the agent's own generated or imagined content
pollute the user's fact base, and (3) never forgetting, so that stale trivia degrades
precision over time.
We introduce \textbf{MnemoBench}, a reproducible benchmark with
three task families targeting exactly these behaviours, with ground truth fixed by a
generator rather than judged post~hoc. We evaluate Nemos, an embeddable memory kernel
with bitemporal contradiction invalidation, namespace isolation between user facts and
agent self-narrative, and FSRS-style decay. On belief update, contradiction invalidation
cuts stale-answer leakage from \bucSLRnone{}\% to \bucSLRfull{}\%, at a moderate recall
cost (update accuracy \bucUAnone{}~$\rightarrow$~\bucUAfull{}\%) that exposes a
precision/recall knob; we further show that an earlier lexical contradiction detector
misses attribute-replacement updates and that a semantic detector recovers them
(leakage \bucSLRvone{}~$\rightarrow$~\bucSLRfull{}\%). Namespace isolation reduces
self-pollution from \aspPRshared{}\% to \aspPRiso{}\% with no recall loss. Decay suppresses
stale-trivia leakage from \forTLnone{}\% to \forTLdecay{}\% while retaining important facts.
We release MnemoBench and all harness code.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% The gap: memory benchmarks measure recall; real long-term failure is maintenance.
Memory systems for LLM agents (e.g.\ MemGPT/Letta~\cite{memgpt}, mem0~\cite{mem0},
Zep/Graphiti~\cite{zep,graphiti}) are commonly assessed on multi-session question answering
such as LoCoMo~\cite{locomo} and LongMemEval~\cite{longmemeval}, which primarily stress
\emph{retrieval}. Yet the failures that erode trust in a long-lived assistant are different:
\begin{itemize}
  \item \textbf{Belief staleness.} A fact changes (job, city, diet, relationship) and the
  system keeps surfacing the old value as if current --- a failure mode recent work on
  knowledge updating in memory systems highlights as both common and hard~\cite{fama}.
  \item \textbf{Self-pollution.} In companion/agent settings the model emits first-person
  or speculative content; if mis-attributed it enters the user profile and is later returned
  as the user's own authoritative fact.
  \item \textbf{No forgetting.} Append-only stores accumulate one-off trivia that crowds out
  salient facts and lowers retrieval precision.
\end{itemize}
We make two contributions. (i) \textbf{MnemoBench}, a benchmark isolating these three
behaviours with generator-fixed ground truth (\S\ref{sec:bench}). (ii) An evaluation of the
\textbf{Nemos} memory kernel (\S\ref{sec:system}) showing each mechanism is responsible for a
measurable, ablatable improvement (\S\ref{sec:results}), including a before/after on a real
defect we found and fixed in the contradiction detector.

\section{Related Work}
\label{sec:related}
\paragraph{Memory architectures.} MemGPT/Letta~\cite{memgpt}, mem0~\cite{mem0},
Zep/Graphiti's temporal knowledge graph~\cite{zep,graphiti}. Contrast: layered separation,
explicit invalidation semantics, source-authority gating.
\paragraph{Temporal/ bitemporal modelling.} Graphiti uses edge validity
intervals~\cite{graphiti}; Nemos keeps materialised world-time and system-time validity
fields on each memory record.
\paragraph{Forgetting.} FSRS / spaced-repetition retrievability~\cite{ssp,fsrs} applied to
machine memory rather than human review scheduling.
\paragraph{Benchmarks.} LoCoMo~\cite{locomo} and LongMemEval~\cite{longmemeval} are
recall-centric. Closest to our thesis is the concurrent work of Uddin et al.~\cite{fama},
whose \emph{Memora} benchmark and Forgetting-Aware Memory Accuracy (FAMA) metric explicitly
penalise reliance on obsolete or invalidated memory --- corroborating the
recall-to-maintenance shift. MnemoBench is complementary: rather than a single aggregate
score, it isolates each maintenance mechanism (invalidation, isolation, decay) through
single-mechanism ablations, and additionally surfaces a before/after on a real detector fix.

\section{The Nemos Memory Kernel}
\label{sec:system}
Nemos is an embeddable memory kernel. We describe only the mechanisms under test.
\subsection{Layered memory and source authority}
Five layers (episodic, semantic, personal\_semantic, procedural, archival). Every record
carries \texttt{source.authoritative} (user-stated vs.\ model-derived); derived content is
barred from authoritative personal facts (invariant I4).
\subsection{Bitemporal contradiction invalidation}
Records carry world-axis (\texttt{valid\_\allowbreak at}/\texttt{invalid\_\allowbreak at}) and system-axis
(\texttt{created\_\allowbreak at}/\texttt{expired\_\allowbreak at}) timestamps and a
\texttt{belief\_\allowbreak state}~$\in$~\{active, invalidated, superseded, corrected\}. During offline
reflection, a new fact that contradicts an existing \texttt{personal\_\allowbreak semantic} anchor marks
the old one \texttt{invalidated}; default retrieval returns only \texttt{active} records.
\paragraph{A real defect: lexical vs.\ semantic detection.}
The earlier detector prefilters contradiction candidates by character-bigram Jaccard
similarity. This reliably catches strong negations (``left Google'') but \emph{misses
attribute replacement} where the new value is lexically dissimilar (vegetarian
$\rightarrow$ pescatarian). We replace the prefilter with embedding-cosine candidate
retrieval and add a same-attribute, mutually-exclusive reconciliation pass over existing
personal facts. \S\ref{sec:results} quantifies the before/after.
\subsection{Namespace isolation (anti-self-pollution)}
User facts live under \texttt{forUser(uid)}; agent self-narrative under
\texttt{forUser(persona:pid)} --- a physically separate keyspace. Retrieval of user facts
cannot surface persona content.
\subsection{FSRS-style decay}
Each record has stability $S$ and retrievability $R=\exp(-\Delta t / S)$ --- a simplified
exponential variant of FSRS-style spaced-repetition memory (the difficulty parameter is
carried in the schema but not yet used by the update rule). Access reinforces $S$; records
with $R$ below a cold threshold, zero recent access, after a dormancy window are marked
cold and hidden from default search (archival is never cooled).

\section{MnemoBench}
\label{sec:bench}
\subsection{Design principles}
Ground truth is \emph{fixed by the generator}: each item's fact script (which attribute,
which values, in what order; which persona statements are traps) is decided first, then
rendered into natural-language sessions. Scoring isolates \emph{memory quality} from
\emph{generation quality}: an LLM judge inspects only the \emph{set of retrieved records}
and decides whether the expected fact is present and whether a forbidden (stale/leaked)
fact is presented as current. The judge never writes the final answer.
\subsection{Task families}
\paragraph{BUC --- Belief Update \& Contradiction.} A single-valued user attribute changes
1--3 times across sessions; the probe asks for the current value.
\textit{Update Accuracy} (expected present) and \textit{Stale Leakage Rate} (a prior value
presented as current; lower better).
\paragraph{ASP --- Anti-Self-Pollution.} User statements interleaved with persona
self-statements, some crafted as plausible traps. Probes query user facts.
\textit{Pollution Rate} (persona fiction returned as authoritative user fact; lower better)
and \textit{User-Fact Recall}.
\paragraph{FOR --- Forgetting \& Salience.} Durable important facts mixed with one-off
trivia at older timestamps; salient facts are revisited during the retention interval.
\textit{Trivia Leakage} (cold trivia still surfacing; lower better) and
\textit{Important-Fact Retention} (guardrail; must stay high).
\subsection{Item schema and scoring}
Each item is a JSON record with an ordered list of \texttt{sessions}
(\texttt{\{speaker, text, contentDate?\}}) and one or more \texttt{probes}
(\texttt{\{query, expected[], forbidden[]\}}). Labels are derived deterministically from
the fact-script for all three tasks, so they cannot drift from the rendered narrative:
for BUC the last scripted value is the only \texttt{expected} current value and all earlier
values are \texttt{forbidden}; for ASP \texttt{expected} is the scripted user fact and
\texttt{forbidden} is each trap's \emph{misattribution} --- the distilled false user fact
that would result from misattributing the persona statement (using the trap's full sentence
instead measurably inflates the pollution rate with judge topical-overlap false positives);
for FOR \texttt{expected} is the scripted important fact and \texttt{forbidden} is every
scripted trivial item. The judge receives the query, the \texttt{expected} and
\texttt{forbidden} lists, and the retrieved record set, and returns two booleans ---
\texttt{contains\_expected} and \texttt{contains\_forbidden} --- where a record that
explicitly marks a forbidden value as past does \emph{not} count as a leak.

\section{Experimental Setup}
\label{sec:setup}
% Models, ablation arms, n, judge model, reproducibility.
The frozen June--July 2026 runs use OpenAI \texttt{gpt-4o} for extraction/reflection and
\texttt{text-\allowbreak embedding-\allowbreak 3-\allowbreak small} for embeddings; the judge is \texttt{gpt-4o}. These are
historical run identifiers, not current model recommendations; replacing any model creates
a new, non-comparable run. We report
$n=\nItems{}$ items per task. A memory-system run that fails all transient-error retries is
scored as an empty retrieval (all its probes count as misses, matching the external
baseline's path); a judge call that fails all retries excludes the probe from the rates and
is reported separately (zero such failures in the frozen runs). Each task changes one named
mechanism while the local runner configuration is held fixed; observed differences are
evidence consistent with that mechanism in this frozen setup, not universal causal estimates:
\begin{itemize}
  \item BUC: \texttt{semantic} (current configuration) vs.\ \texttt{lexical} (earlier configuration) vs.\ invalidation-off.
  \item ASP: namespace-isolated vs.\ shared store.
  \item FOR: decay-on vs.\ decay-off. To isolate decay we disable reflection in both arms and
  use cold threshold $0.3$, dormancy $0$, with a 120-day retention interval; important facts
  are accessed during the interval (modelling that salient facts are revisited).
\end{itemize}
As one external reference point we run mem0 (v2.0.8) on the BUC task with the same models and
the identical judge. As a standard-benchmark cross-anchor we additionally evaluate a
\lmeN{}-question slice of the LongMemEval~\cite{longmemeval} \emph{knowledge-update} subset
(oracle setting), following its generate-then-judge QA-accuracy methodology, ablating
invalidation (semantic vs.\ off).

\paragraph{Belief update (BUC).} Stale leakage falls monotonically across the ablation
ladder: \bucSLRnone{}\% with no invalidation, \bucSLRvone{}\% with the earlier lexical
detector, and \bucSLRfull{}\% with the semantic detector --- the contradiction mechanism more
than halves stale answers, and the lexical$\rightarrow$semantic change alone removes a further
third of the leakage by catching attribute-replacement updates the lexical prefilter misses.
This gain is not free: update accuracy drops from \bucUAnone{}\% (floor) to \bucUAfull{}\%
(semantic), i.e.\ aggressive invalidation occasionally retires a still-current fact. BUC thus
exposes a precision/recall knob absent from the other two tasks; we regard the operating point
as tunable (candidate-similarity threshold, reconciliation conservativeness) rather than fixed.
The external system, mem0, retains contradicted facts as active alongside their replacements
(it appends without invalidating the old), placing its leakage near the no-invalidation floor.

\paragraph{External cross-anchor (LongMemEval).} The same effect appears on a standard
benchmark: on a \lmeN{}-question slice of the LongMemEval knowledge-update subset (QA accuracy,
generate-then-judge), enabling semantic invalidation raises accuracy from \lmeAccNone{}\% to
\lmeAccFull{}\% --- a $+10$-point gain attributable solely to the invalidation ablation. The
absolute level is modest (Nemos is used as a from-scratch memory over the oracle evidence
sessions, without LongMemEval-specific tuning), so we read the \emph{delta}, not the level, as
the result: belief maintenance helps even on recall-style external data.

\paragraph{Anti-self-pollution (ASP).} This is the largest and cleanest effect. Across
$250$ user-fact probes, namespace isolation reduces the pollution rate from \aspPRshared{}\%
(a single shared store, as in append-only designs) to \aspPRiso{}\% --- a $\sim$60$\times$
reduction --- while user-fact recall is statistically unchanged (\aspUFRshared{}\% vs.\
\aspUFRiso{}\%). Physically separating the agent's self-narrative keyspace from the user's
facts essentially eliminates the failure mode at no cost to recall.

\paragraph{Forgetting (FOR).} Over $146$ salience probes, decay cuts trivia leakage from
\forTLnone{}\% to \forTLdecay{}\% while important-fact retention is unchanged
(\forIFRnone{}\% vs.\ \forIFRdecay{}\%): unreferenced trivia is cooled out of default
retrieval without dropping the revisited important facts.

\section{Discussion and Limitations}
\label{sec:limits}
\paragraph{LLM-judge dependence.} Both rendering and scoring use an LLM; we mitigate with a
set-membership judge (no answer generation), low temperature, and a human-audited sample.
\paragraph{Self-generated data.} Items are synthetic; we report only relative differences
under identical data and add a standard-benchmark slice (LongMemEval) as a cross anchor.

\paragraph{Frozen implementation snapshot.} The paper reports the committed benchmark
artifacts listed in \texttt{bench/results/manifest.json}. Later SDK releases add structured
claim reconciliation and broader recall improvements; those changes are not silently folded
into the tables here and require a new benchmark release.
\paragraph{FOR isolation choices.} Disabling reflection and using aggressive decay parameters
isolate decay cleanly but do not reflect the full-system default; we report them explicitly.
\paragraph{Residual leakage.} The semantic detector does not reach zero stale leakage on
generated hard cases (lexically and semantically close value pairs); we analyse failures in
\S\ref{sec:results}.

\section{Conclusion}
Long-lived memory should be judged on maintenance, not just recall. MnemoBench operationalises
this, and each Nemos maintenance mechanism yields a measurable, ablatable gain.
