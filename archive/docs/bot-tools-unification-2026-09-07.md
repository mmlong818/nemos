# 助理、Bot 与工具：第一阶段入口整合

## 已落地

统一职责：助理面向用户目标；Bot 提供专业工作流程；工具执行具体操作。

原来的 15 个能力保持原有 backendId、执行器与存储格式，拆分为：

| 内置流程 Bot（无需添加） | 原执行器 |
| --- | --- |
| 演示制作 | presentation-builder |
| 文档写作 | document-draft |
| 资料研究 | research-brief |
| 港股资料 | market-briefing |
| 问题梳理 | thinking-workbench |
| 产品设计 | product-design |
| 会议纪要 | meeting-minutes |
| 网页报告 | html-report |
| 方案比较 | decision-brief |
| 商务推进 | business-deal |
| 市场机会 | market-opportunity |

工具页保留翻译、语音转写、轻量润色和高级扩展构建。高级扩展构建仍使用 ability-builder，不等同创建文字 Bot。

Bot 市场合并展示 11 个内置流程和原有 8 个文字模板，可按执行方式、分类、关键词筛选。“我的 Bot”同时显示已有个人文字规则与无需添加的内置流程。

内置流程卡片通过白名单深链接打开原执行页的对应表单，不会打开即执行。材料上传、交付格式、偏好记忆开关、任务队列、历史记录与成果继续使用原有机制。两个页面共用 workflow-catalog.js，防止展示与执行映射漂移。

## 明确保留的限制

- 这是产品入口与既有执行流程的整合，不是把两套运行引擎合并。
- 内置流程当前不能编辑成个人 Bot，也不能放进文字协作团队。
- 文字 Bot 的工具与长期记忆仍关闭，没有通过修改文案扩大权限。
- 内置流程使用应用已有模型和工具配置；页面中的可用状态不代表已逐个验证真实外部服务。
- 文字协作与原流程任务暂时保留各自记录。原任务、成果、Bot、密钥和记忆未迁移或删除。
- 助理尚未获得通用的“任意个人 Bot 调用任意工具”机制，不宣称已支持自动跨流程编队。

## 验证

- 99 项相关单元与隔离集成测试通过：包括全部 11 个流程的真实前端提交函数映射、材料与关闭记忆选项传递、深链接不执行、原任务持久化与队列恢复、文字 Bot 隔离。
- verify-workflow-bots.ps1：11 个真实市场链接 × 桌面/手机共 22 次打开正确表单；工具分区、未知 Bot 拒绝和文字筛选通过。
- verify-workbench-navigation.ps1：15 个路由 × 4 个宽度共 60 组图标/文字坐标一致。
- 检查桌面和手机截图；无横向溢出。本轮没有进行真实模型付费调用或外部工具验收。

服务重启命令被执行策略拒绝，原服务继续运行。前端资源热加载并兼容旧进程的导航标题；服务端导航源文件也已更新，下次正常启动会直接采用新标题。
