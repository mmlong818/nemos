# 文字 Bot 候选池

本轮将服务器内部 AssistantBotStore.plan 的 planning 选项接到已持久化的 planned-text-v1 模式。必须为自动分派且没有手动角色指定；普通 HTTP 输入中的同名参数不生效，现有服务器调用仍产生 fixed-v1 任务。

候选池为当前用户已启用、非市场 Bot 的规则快照，最多沿用存储上限 40 个。排除其他用户和停用条目。规划不再只看旧名称路由选中的角色，模型可选不同专家；最终仍至多三名专家与小丑鱼汇总，工具关闭。

发现阶段只提供每个候选的 ID、名称、规则前 240 字符，并显式标记摘要截短；执行阶段使用完整冻结规则。完整规则参加恢复指纹，不因摘要相同而复用已变化的规划。摘要可能降低匹配质量，不能声称已通过真实模型选人质量验收。

运行前拒绝重复候选、停用/市场快照、无效角色/规则/版本和冒用主助理 ID。入队后的编辑不回写冻结快照；若用户要停止旧任务，应取消任务，而不是假定停用 Bot 会自动撤销已入队工作。

26 项相关测试通过，类型检查通过。新增验证跨用户隔离、冻结完整规则、从全候选中选择专家、摘要限制和非法快照零模型调用。使用模拟模型，无费用、无用户数据变更。

尚未对页面开放，未重启当前服务。专业文件执行器不在此候选池中，完整自主技能编排与显式启用/预算入口仍待实现。
