连接和数据，都在这里

模型服务和外部数据采用同一套状态表达：能否使用、由谁提供、下一步做什么，一眼就能看懂。

模型与服务

按目录时间优先检查较新的候选；可手动固定型号。目录顺序不等于能力排名，密钥只加密保存在本机。

读取当前连接状态
候选目录常用列表按用途精简；高级目录仅供手动选择，不代表已验证可用。

数据连接

连接状态来自运行环境；运行时就绪不等于账号数据已验证，具体访问以实际操作结果为准。

可安装能力

预置能力会明确说明是否依赖外部服务，安装后统一接受权限和运行审计。

自定义插件

用于导入第三方、本地或自建 MCP 插件；普通用户无需配置。

高级与排错

打开运行日志
