# 小丑鱼 能力地图

状态：交互设计稿
日期：2026-08-04
范围：能力中心原型与后续实现边界，不表示生产功能已经接通

## 1. 组织原则

能力按“用户最终要完成什么”组织，不按模型、智能体、提示词或实现方式组织。

- 一次能完成的任务直接在能力详情中运行。
- 需要多轮判断、阶段成果或长期跟进的任务进入独立工作台。
- 多项底层流程可以共同支撑一个能力，不向用户拆成工具列表。
- 相似能力不重复出现：增强已有能力时，只升级原入口。

## 2. 当前能力

| 能力 | 用户得到什么 | 适合的页面 | 轻量记忆 |
|---|---|---|---|
| 做 PPT | 故事线、逐页预览、可编辑演示文件 | 演示工作台 | 演示节奏、常用版式、品牌偏好 |
| 写正式文档 | 规范文档与打印版本 | 文档工作台 | 文笔、标题层级、表格习惯 |
| 做网页报告 | 适配电脑、小屏和打印的网页 | 网页工作台 | 阅读密度、排版、图表风格 |
| 深入研究一个问题 | 研究报告、证据清单和待确认项 | 研究工作台 | 研究深度、来源偏好、引用格式 |
| 比较方案并给建议 | 方案比较、条件化建议和风险边界 | 任务详情 | 判断原则、风险偏好、表格习惯 |

| 评估商业机会 | 机会判断、主要分歧、风险和验证实验 | 机会评估工作台 | 风险偏好、资源上限、验证方式 |

## 3. 哪些能力合并，哪些单独成页

### 合并进已有能力

- 做 PPT：把故事线、内容到版式的匹配、逐页编辑、演讲模式和多格式导出统一放进一个入口。
- 深入研究一个问题：把问题拆分、资料搜集、来源判断、事实核对和报告复查统一为一条研究流程。
- 比较方案并给建议：只负责已有方案之间的选择，不承担从零定义产品或长期项目推进。

### 使用独立工作台

- 梳理复杂问题：需要保留逐步修正的思考链。
- 设计产品方案：需要项目级成果连续传递，不能每一步重新讲背景。
- 推进商务合作：需要按合作对象维护进展、卡点、承诺和下一步。
- 评估商业机会：运行时间较长，需要展示多个视角、分歧和验证计划。
- 做 PPT：需要页面缩略图、画布、属性检查和导出，不适合塞进聊天气泡。

### 作为内部创建流程

“保存成常用流程”对普通用户只展示目标、输入、输出、边界和试运行。内部如何生成、检查或打包能力不进入产品语言。

## 4. 统一操作流程

```text
描述目标，或点一个常用能力快捷入口
→ 如果已有未完成任务，可从“继续上次”恢复目标和材料
→ 小丑鱼 自动安排合适能力，不要求用户先查找或分类
→ 用户只在安排明显不合适时改选
→ 补充一句任务目标和必要材料
→ 查看本次会参考的少量习惯，可临时关闭或调整
→ 预检输入、外部访问和风险边界
→ 运行并持续保存进度
→ 在进行中查看、暂停或补充信息
→ 完成后进入对应文件或项目工作台
→ 修改、导出或保存为常用流程
```

流程默认只要求“一句目标或一份材料”。只有缺少会明显改变结果的信息时才追问。

## 5. 记忆使用边界

每项能力最多在入口展示一行本次会参考的习惯，默认只影响表达和呈现，不替用户做事实判断。

- 可以使用：文笔、标题层级、排版密度、常用格式、风险偏好、复盘后的工作习惯。
- 需要确认：公司事实、对外口径、价格、合作红线、法律判断和真实市场数据。
- 不应保存：密钥、私人配置、未经确认的敏感材料和一次性的临时假设。
- 用户关闭“按我的习惯生成”后，本次运行不注入长期习惯。

## 6. 历史、文件与记忆

- “进行中”只放正在运行或等待补充的任务。
- “历史”保存成功、部分完成、失败和取消的任务；打开结果进入文件，再次使用会新建任务。
- 文件的每次编辑保存在文件版本中，不重复制造任务历史。
- 记忆只提炼用户确认后的习惯，不复制整段任务内容，也不因为删除历史而自动消失。
- 删除时分别确认任务记录、关联文件和由本次任务产生的记忆，避免误删。

## 7. 运行边界

- 研究结果必须区分已核验、推断和未知。
- 商业机会推演是形成假设，不替代真实访谈、市场数据或实验。
- 商务合作不会自动对外发送、报价、承诺或给出法律意见。
- 产品方案中未经验证的用户和市场判断继续保留为假设。
- 只有真实转换器可用时，才显示可编辑 PPT、Word 或 PDF 已成功生成。

## 8. 原型验收

1. 首屏不要求用户搜索或分类能力；描述目标后可以自动匹配 11 项能力。
2. 默认只显示 6 个常用快捷入口，“查看全部”不会阻断主流程。
3. 点常用能力后直接进入材料准备，不再增加一次“查看后再继续”。
4. 每项能力都显示需要、会得到、怎么完成、需要注意和本次记忆影响。
5. 目标输入、材料准备、执行中、历史和打开结果形成完整闭环。
6. 开始页可以恢复上次任务，历史页可以再次使用且不覆盖原记录。
7. 文件版本留在文件内，记忆影响与任务历史分开说明。
8. 小屏下能力列表可滚动，选中后能平滑进入详情。
9. 产品界面和普通说明只使用 小丑鱼 自己的名称与语言。
