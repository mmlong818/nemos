# 小丑鱼能力地图

状态：当前实现说明
更新：2026-08-10

## 1. 面向用户的 13 项能力

| 用户名称 | 内部能力 | 默认结果 | 主要用途 |
|---|---|---|---|
| 做 PPT | presentation-builder | PPTX | 汇报、提案、课程和路演 |
| 写正式文档 | document-draft | DOCX | 方案、说明、总结和长文 |
| 深度研究 | research-brief | HTML | 搜索、核验与可追溯结论 |
| 查港股资料 | market-briefing | Markdown | 公告、关注列表与行情快照 |
| 梳理复杂问题 | thinking-workbench | HTML | 事实、假设、矛盾和验证 |
| 设计产品界面 | product-design | HTML | 用户流程、页面和验收 |
| 开发项目 | project-development | Markdown | 读取指定项目、形成修改提案并验证 |
| 整理会议纪要 | meeting-minutes | DOCX | 决定、行动项、责任与风险 |
| 做网页报告 | html-report | HTML | 可直接打开的独立报告 |
| 比较方案 | decision-brief | Markdown | 证据、收益、代价与失效条件 |
| 推进商务合作 | business-deal | HTML | 关键人、异议、边界和跟进 |
| 模拟市场机会 | market-opportunity | HTML | 需求、竞争、情景和失效条件 |
| 生成新能力 | ability-builder | HTML | 把重复流程沉淀为本机能力 |

用户名称应稳定、直白。内部编号只用于代码、接口和测试。

## 2. 内部辅助能力

OCR、文档转换、文章润色、信息源发现、流程搭建、群聊进展等能力可被聊天、文件或运行时调用，但不必全部显示在普通能力首页。

公开能力数量与内部能力数量不要求相同。

## 3. 不在当前范围

- 动车实时余票；
- 航班实时价格与库存；
- 酒店实时房态；
- 餐馆实时座位。

系统可以帮助整理已有材料，但不能把缺少适配器的实时信息描述为已查询结果。

## 4. 入口

- 聊天：从自然语言目标进入；
- 能力：自动选择或直接选择；
- 文件：围绕当前工作副本页内处理；
- 工作：继续处理历史任务或查看已有结果；
- 后台计划：按保存的任务配置触发。

所有入口最终进入同一任务、运行和交付物模型。

## 5. 结果

结果分为：

- 文档：DOCX、PDF、Markdown；
- 演示：PPTX；
- 数据：XLSX、JSON；
- 网页：HTML；
- 运行记录：状态、进度、错误和恢复信息。

文件后缀不是产品层级。用户先看到结果内容，再决定打开或下载。

## 6. 记忆

普通对话使用相关记忆。能力任务可只使用交付偏好。偏好不得改变：

- 事实核验；
- 来源等级；
- 审批要求；
- 权限边界；
- 当前任务明确格式；
- 风险提示。

## 7. 任务与版本

- 首次执行建立任务和第一个结果；
- 继续处理同一成果会沿用任务，并记录上一版和当前版本；
- 从无关目标重新开始时才创建新任务；
- 一次任务可以转为每日或按使用频率重复执行；
- 旧版本和旧文件保留；
- 失败与取消保留真实状态；
- 结果、运行和任务可以相互定位；
- 文件工作台的版本记录与能力任务历史是两个层次。
