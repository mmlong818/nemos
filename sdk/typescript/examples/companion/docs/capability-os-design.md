# 小丑鱼能力运行架构

状态：当前实现与边界
更新：2026-08-10

## 1. 目标

让聊天、能力、文件和计划任务共享同一套执行事实，而不是各自维护一套不可追踪的状态。

## 2. 分层

### 用户入口

- 聊天
- 能力页
- 文件页
- 工作页
- 计划任务

### 需求与匹配

把自然语言目标映射到公开能力。用户已经直接选择时，不再重复匹配。

### 能力运行时

负责：

- 任务模型；
- 输入材料；
- 结果格式；
- 能力提示；
- 原生产物渲染；
- 交付物登记。

### Agent Runtime

负责：

- 持久运行；
- 工具调用；
- 事件和检查点；
- 预算；
- 取消与恢复；
- 用户确认；
- 多 Agent 编排。

### 工具与扩展

- 内置工具；
- Skill；
- MCP；
- Agent App；
- 来源连接器。

扩展必须声明权限和执行方式。缺少沙箱或授权时失败关闭。

### 记忆

- 普通对话召回任务相关记忆；
- 能力可只召回交付偏好；
- 用户与角色命名空间分离；
- 运行状态不能写成用户事实。

## 3. 统一状态

任务状态、Agent 运行和交付物是三个对象：

- 任务：用户要完成什么；
- 运行：系统如何执行以及当前状态；
- 交付物：最终可打开的结果。

它们通过编号关联，但不能相互替代。

## 4. 当前完成

- 16 项公开能力；
- 自然语言匹配与直接选择；
- 持久任务队列；
- 进度、取消、失败和重试；
- 交付物预览与下载；
- 聊天交付账本；
- 计划任务；
- 对话、能力接力和直接执行统一沉淀为任务；
- 同一成果的继续处理、版本关系和上一版定位；
- 一次任务转为每日或按使用频率重复执行；
- Skill 安装、归档、恢复和审查；
- MCP 与 Agent App 注册表；
- 用户动作网关和审批；
- Node 权限沙箱与 Windows LPAC 宿主；
- 受控多 Agent DAG；
- Office 读取、工作副本、页内处理和导出；
- 港股公告与行情快照的只读适配。

## 5. 部分完成

- 新能力可以生成和注册，但自动质量改进仍以人工审查为主；
- 运行成本只对维护表中的已知模型估算；
- 偏好召回已经接通，但尚无逐项应用记录和单次忽略；
- Office 预览对 PDF 最完整，DOCX、PPTX 和 XLSX 为结构化预览；
- Skills 可安装和复用，但外部新增项仍需用户主动导入。

## 6. 明确排除

- 动车实时余票；
- 航班实时价格与库存；
- 酒店实时房态；
- 餐馆实时座位；
- 自动交易；
- 未经确认的高影响外部写操作。

## 7. 不变量

1. 事件记录是运行状态的事实源。
2. 未知写操作默认拒绝。
3. 副作用需要用户动作或审批。
4. 取消必须传递到模型和工具。
5. 重试不能重复已确认但终态未知的副作用。
6. 扩展缺少安全运行条件时失败关闭。
7. 用户记忆和角色记忆分离。
8. 结果必须是可打开的真实产物或明确的失败。
