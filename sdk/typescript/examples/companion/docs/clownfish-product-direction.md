# 小丑鱼产品方向

状态：执行基线  
更新：2026-08-10

## 核心定位

小丑鱼不是角色集合，也不是要求用户先理解能力名称的 Agent 平台。它是一位本机优先的长期工作伙伴：用户说明一次目标，小丑鱼保留上下文、调用合适能力，并把工作推进成可以继续编辑的成果。

## 首要用户

首要服务需要处理资料、方案、汇报和办公文件的知识工作者，包括产品、运营、商务、行政、研究、顾问和小团队负责人。

他们首先需要：

1. 不学习工具名称也能开始；
2. 聊天、任务、文件之间不重复说明；
3. 得到能继续修改的文档、演示、表格或网页；
4. 看见真实进度、失败原因和恢复入口；
5. 知道系统记住了什么、本次用了什么，并能纠正或关闭；
6. 保持文件、密钥与私人资料的控制权。

学习和专家能力继续保留，但作为任务内部的工作方式，不以人物列表出现在首页。开发能力面向有明确项目文件夹的用户，不把命令行作为新手主流程。

首页的基本单位是平等的对话线程，不存在“主对话”特例。点击“新对话”会立即建立空白对话，不用先做选择；用户可在空白页按需要切换为“完成任务”或“学习辅导”，也可以删除不再需要的线程。老师和专家的具体身份不需要向用户展示。每个线程独立保留上下文、文件、进度和结果，可以并行推进。

## 产品主线

所有入口共享同一条工作链路：

> 对话 → 材料 → 能力执行 → 进度 → 结果 → 文件工作副本 → 修改与版本

页面可以分开，但上下文、来源和结果位置不能断开。项目只在任务变成长期工作后出现，不要求新用户预先建立。

## 开发优先级

### P0：连续完成

- 保持对话原文、摘要、附件和相关记忆随任务交接；
- 任务完成后回到原对话并能进入文件工作台继续；
- 同一成果后续修改形成版本，不重复建立无关任务；
- 所有状态来自持久运行记录。

当前状态：对话来源、能力接力、任务状态、产物和版本关系已经统一保存；一次任务可继续处理，也可转为重复任务。

### P1：可信记忆

- 严格区分用户、角色和项目事实；
- 展示本次实际采用的少量习惯；
- 支持单次关闭、纠正和忘记分类记忆；
- 不向普通用户展示原始归档结构。

### P1：成果工作台

- 优先深化文档和演示，再完善表格；
- 支持提纲、页面、局部修改、版本比较、引用与核验；
- 用真实 Word、PowerPoint 和 Excel 文件验收兼容性。

### P2：重复工作

- 从重复任务中沉淀“我的做法”；
- 保存模板、版式和审查要求；
- 只接入能够明显减少手工搬运的本地文件或服务连接器。

## 暂不主攻

- 首页增加更多角色或能力卡片；
- 用多智能体数量作为卖点；
- 大型企业多租户协作；
- 与专业 IDE 正面竞争；
- 与核心工作链路无关的实时生活查询。

## 衡量标准

- 新用户获得第一个可用成果所需时间；
- 第二次使用时减少的重复说明；
- 成果在两轮以内达到可交付的比例；
- 对话交接、结果回流和文件继续编辑的成功率；
- 记忆纠正、关闭和忘记操作的成功率；
- 一周内重复使用同一工作方式的比例。
