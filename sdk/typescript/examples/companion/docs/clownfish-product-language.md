# 小丑鱼产品语言

状态：当前命名基线
更新：2026-08-06

## 1. 品牌

- 产品名：**小丑鱼**
- 英文名：**Clownfish**
- “小丑鱼”指应用本身，不再设置一个同名之外的默认主角色。
- 记忆内核在开发文档中称 **Nemos Memory SDK**，普通界面只说“记忆”。

## 2. 主导航

固定使用：

- 聊天
- 能力
- 文件
- 工作
- 设置

不要混用“能力中心 / 技能市场 / Agent 商店”作为同一页面名称。

## 3. 工作页

固定使用：

- 任务
- 结果
- 运行
- 记忆

“结果”用于用户可打开的交付物；“运行”用于进度、错误、取消、重试和恢复。

## 4. 能力页

推荐用词：

- 直接说，你想完成什么？
- 自动选择并继续
- 直接选择能力
- 开始处理
- 进行中
- 已完成
- 再次使用

禁止用词：

- 准备能力
- 添加一个能力
- 创建项目后继续
- AI 正在施展魔法
- 已智能完成但没有真实结果

## 5. 文件页

固定用词：

- 最近文件
- 新建文件
- 打开文件
- 原文件
- 可编辑内容
- 处理结果
- 修改记录

不要用“素材仓”“文档中台”等增加理解成本的名称。

## 6. 记忆页

面向用户的层名称：

- 习惯与做法
- 个人偏好
- 稳定事实
- 经历与进展
- 原始归档

产品文案要明确：忘记分类记忆不会删除原始归档。

## 7. 专家

专家名称使用“作用 + 顾问/教练/师”，例如：

- 可行性顾问
- 产品顾问
- 决策顾问
- 思考教练
- 系统架构师

不使用现实人物姓名、外部产品角色名或容易误导为真人背书的头像。

## 8. 状态

统一状态：

- 排队中
- 运行中
- 已完成
- 失败
- 已取消
- 等待确认

状态必须来自真实运行记录，不能用模糊文案掩盖失败或尚未执行。
