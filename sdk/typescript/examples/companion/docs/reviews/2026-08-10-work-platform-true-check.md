# 工作平台真实检查（2026-08-10）

## 检查视角

- **普通白领**：关注能否在不理解 Agent、专家角色和连接器的情况下完成资料整理与定期工作。
- **产品与交付负责人**：关注任务能否带着资料执行、专家协作是否真的形成后台作业，以及失败和取消是否可追踪。

## 实际路径

1. 打开资料页，创建一份本地文字资料；
2. 新建任务，展开“参考资料”，选择刚创建的资料并保存；
3. 确认任务卡显示“1 份资料”；
4. 打开自动化页，确认每日任务可编辑、暂停和立即运行；
5. 打开协作页，对测试任务启动“小丑鱼组织协作”；
6. 在运行页确认出现包含三项专家检查与小丑鱼最终交付的编排作业；
7. 取消测试作业，确认状态变为“已取消”；
8. 使用 390 × 844 小屏检查资料页、连接状态、横向标签和底部导航；
9. 清理真实检查创建的任务与资料。

## 发现与修正

- **已修正**：专家编排过程中生成的内部一次任务曾出现在“可组织的任务”列表，造成递归组织的误导。协作页现在只显示长期任务。
- **已确认**：用户不需要选择专家；专家职责由任务类型决定，最终节点固定回到小丑鱼。
- **已确认**：资料不会全量注入。只有任务中明确勾选的最多 8 份资料会进入执行上下文。
- **已确认**：微信资料和 X 会展示真实连接状态；联网搜索明确依赖可用模型或搜索工具。
- **已确认**：小屏使用单列内容和横向工作标签，主要操作仍可完成。

## 结论

工作中心已经从“任务记录页”扩展为可实际使用的本地工作平台：任务、工作空间、自动化、协作、资料、结果、运行和记忆使用同一套持久数据与执行记录。未发现阻断核心流程的问题。
