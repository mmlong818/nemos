# 小丑鱼本机应用

当前应用版本：**0.2.19**
内置记忆核心：**Nemos 0.7.5-alpha.17**
文档复核：**2026-08-10**

小丑鱼可以作为网页应用运行，也可以构建成 Windows 便携客户端。任务、能力、文件和工作页共享同一套本机数据。

## 快速运行

在 **sdk/typescript** 目录执行：

~~~powershell
npm install
npm run companion
~~~

默认打开 <http://localhost:8787>。

可用环境变量：

| 变量 | 作用 |
|---|---|
| **PORT** | 修改服务端口 |
| **CLOWNFISH_HOME** | 修改应用数据目录 |
| **COMPANION_USER** | 指定本机用户命名空间；服务部署时应由可信身份映射 |

## 首次使用

1. 设置称呼；
2. 进入能力、文件或工作页，点击左下角 **设置 → 模型连接**，选择服务商、模型和 API Key；
   日常单人对话会自动使用轻量模型，专家、能力和复杂任务继续使用这里配置的主模型；
3. 连接测试通过后保存；
4. 点击“新对话”立即开始；在空白对话中可按需要切换为完成任务或学习辅导，也可以进入能力、文件和工作页；首次发送后会自动生成简短标题，之后可通过左上角搜索快速找回。

离线模式仍可浏览界面、管理本机内容，以及使用不需要模型的功能。

## 当前页面

| 路径 | 页面 | 主要用途 |
|---|---|---|
| **/** | 对话 | 独立对话的新建、搜索、自动命名、切换与删除，三种工作方式、历史、分支、图片和文件附件 |
| **/capabilities** | 能力 | 自动选择或直接选择能力，启动并跟踪任务 |
| **/office** | 文件 | 打开、编辑、处理和导出办公文件 |
| **/tasks** | 工作 | 任务与计划 |
| **/spaces** | 工作空间 | 把同一件事下的多个任务和结果放在一起；支持归档与恢复 |
| **/automations** | 自动化 | 管理每日或按使用频率运行的任务 |
| **/collaboration** | 协作 | 由小丑鱼自动组织专家检查并完成最终交付 |
| **/resources** | 资料 | 保存本地资料、查看数据连接，并把资料选入任务 |
| **/artifacts** | 结果 | 查看和下载交付物 |
| **/runs** | 运行 | 查看执行记录；副作用结果不明时先核对，再决定结束或重试 |
| **/memory** | 记忆 | 查看分类记忆，添加或忘记习惯 |

## 内置能力

当前能力页提供 13 项能力：

1. 做 PPT
2. 写正式文档
3. 深度研究
4. 查港股资料
5. 梳理复杂问题
6. 设计产品界面
7. 整理会议纪要
8. 做网页报告
9. 比较方案
10. 推进商务合作
11. 模拟市场机会
12. 生成新能力
13. 开发项目（指定本地项目文件夹后，可选择只读检查或开发并验证；交付项目修改、可运行结果和验证记录）

一次能力执行会同时登记为任务和结果。继续处理同一成果时沿用原任务并形成连续版本；失败会保留原因和重试入口。一次任务也可以在工作页转为每日或按使用频率重复执行。

工作空间不是开始任务的前置步骤。用户可以先直接开始；当同一件事出现多个任务时，再创建空间，并在新建或编辑任务时选择归入。空间归档不会删除其中的任务和结果。

资料库支持文字笔记、文本文件和网页链接，归档后可以恢复。任务最多明确选择 8 份资料；未选择的资料不会被默认注入模型上下文。自动化页只是已设置频率任务的集中视图，仍使用同一套持久任务和运行记录。协作页不要求用户配置专家，小丑鱼会根据能力类型和本次任务内容重新选择专业检查，并负责最终交付。

### 专家协作

- 专家不是固定聊天角色，而是带有职责、工具方向、执行流程、交付物和复核标准的内部执行单元；
- 当前专业覆盖研究核验、文档编辑、演示设计、数据分析、项目推进、流程自动化、安全隐私、合同风险、视觉分析，以及产品、工程、商业和决策等领域；
- 开发任务中的工程专家会在用户选定的项目范围内进行只读检查，最终修改仍由小丑鱼统一执行；
- 研究专家可以使用已配置的来源工具，工具不可用时必须明确降级，不能把宣传简介当成真实验证；
- 专家任务不读取其他对话或角色的历史记忆；最终交付只使用用户偏好，并同时接收专家产物的提炼摘要和完整原文；
- 普通界面只显示执行了哪些专业检查，不展示专家市场、内部名称或配置来源。

## 文件工作台

- 读取 DOCX、PPTX、XLSX、PDF、TXT 和 Markdown；
- 原文件保留在浏览器本机存储中，不被工作副本覆盖；
- PDF 使用原始文件预览，Office 文件提供结构化预览；
- 编辑和 AI 处理都留在文件页；
- 任务和能力结果可直接建立本机工作副本继续编辑；
- 支持版本记录与恢复；
- 导出 DOCX、PDF、PPTX、XLSX、HTML 和 Markdown。

## 记忆行为

### 任务线程

- 用户消息进入用户命名空间；
- 每个任务保留独立会话上下文，切换任务不会混入其他线程；
- 直接聊聊、完成任务和学习辅导使用各自合适的执行与记忆范围，但界面不暴露内部角色；
- 原始归档与分类记忆分开保存，普通记忆页不展示原始归档；
- 反思、事实失效和领域路由由统一记忆配置开启。

### 能力与文件

- 能力任务统一由小丑鱼接收和交付；专家可以执行受限检查并生成内部产物，但不能代替小丑鱼确认权限、改变长期任务或直接面向用户交付；
- 能力页可选择 **使用我的习惯** 或关闭偏好召回；
- 任务记录会显示本次实际采用的习惯；
- 已完成结果可连同完整原文和提要继续交给另一项能力；
- 开发项目只访问用户明确填写的文件夹，不读取密钥，不删除文件，也不执行推送、发布或部署；
- 文件页的 AI 处理使用偏好召回；
- 偏好召回只查 **procedural** 与 **personal_semantic**；
- 先取最多 12 个候选，再筛选与习惯、文笔、排版或格式相关的最多 6 项；
- 当前请求仍是任务主指令。

### 用户控制

- 记忆页可以明确写入一条全局习惯；
- 可以忘记单条非归档记忆；
- 原始归档受保护，不会被单条忘记或分类清理删除；

## 模型和网络边界

预设服务商包括智谱 GLM、OpenAI、Anthropic Claude、DeepSeek、通义千问、MiniMax 和自定义服务。

- 调用模型时，任务内容和必要上下文会发送给所选服务商；新对话首次发送后还会用日常轻量模型生成短标题；
- 标题生成不调用工具、不写入长期记忆；模型不可用时使用本地规则命名；
- 使用已配置的联网搜索、公开来源或 X 连接器时会访问对应网络服务；未配置的连接器不能视为实时数据源；
- Windows 保存的模型 Key 使用当前用户的 DPAPI 加密；
- 接口与日志不应返回完整密钥；
- 工具、MCP 和 Agent App 按清单、权限和沙箱边界执行。

## Windows 便携客户端

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File examples\companion\client\Build-Clownfish.ps1
~~~

构建脚本会下载并校验：

- Microsoft WebView2 SDK；
- Node 26.5.0 沙箱运行时；
- Python 3.14.6 嵌入式运行时。

输出目录：

~~~text
examples\companion\client\dist\portable\小丑鱼
~~~

用户数据默认不在程序目录。分享便携包前仍应检查是否误带 **~/.clownfish** 或自定义数据目录。
