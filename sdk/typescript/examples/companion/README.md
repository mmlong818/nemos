# 小丑鱼本机应用

当前应用版本：**0.2.19**
记忆核心依赖：**Nemos Memory 0.7.5-alpha.18**
文档复核：**2026-08-15**

小丑鱼可以作为网页应用运行，也可以构建成 Windows 便携客户端。任务、能力、文件和工作页共享同一套本机数据。

## 快速运行

在 **sdk/typescript** 目录执行：

~~~powershell
npm install
npm run companion
~~~

默认打开 <http://localhost:8787>。

可用环境变量：

| 变量 | 作用 |
|---|---|
| **PORT** | 修改服务端口 |
| **CLOWNFISH_HOME** | 修改应用数据目录 |
| **COMPANION_USER** | 指定本机用户命名空间；服务部署时应由可信身份映射 |

## 首次使用

1. 设置称呼；
2. 点击左下角 **设置 → 模型与服务**，选择服务商、模型和 API Key；
   日常单人对话会自动使用轻量模型，专家、能力和复杂任务继续使用这里配置的主模型；
3. 连接测试通过后保存；
4. 点击“新对话”立即开始；在空白对话中可按需要切换为完成任务或学习辅导，也可以进入能力、文件和工作页；首次发送后会自动生成简短标题，之后可通过左上角搜索快速找回。

离线模式仍可浏览界面、管理本机内容，以及使用不需要模型的功能。

## 当前页面

| 路径 | 页面 | 主要用途 |
|---|---|---|
| **/** | 对话 | 独立对话的新建、搜索、自动命名、切换与删除，三种工作方式、历史、分支、图片和文件附件 |
| **/capabilities** | 能力 | 自动选择或直接选择能力，启动并跟踪任务 |
| **/office** | 文件 | 打开、编辑、处理和导出办公文件 |
| **/develop** | 开发 | 选择本地项目，用自然语言实现、修复或检查代码；按需安装项目依赖 |
| **/tasks** | 工作 | 任务与计划 |
| **/spaces** | 工作空间 | 把同一件事下的多个任务和结果放在一起；支持归档与恢复 |
| **/automations** | 自动化 | 管理每日或按使用频率运行的任务 |
| **/collaboration** | 协作 | 由小丑鱼自动组织专家检查并完成最终交付 |
| **/resources** | 资料 | 保存本地资料、查看数据连接，并把资料选入任务 |
| **/artifacts** | 结果 | 查看和下载交付物 |
| **/runs** | 运行 | 查看执行记录；副作用结果不明时先核对，再决定结束或重试 |
| **/memory** | 记忆 | 查看分类记忆，添加或忘记习惯 |
| **/settings** | 设置 | 统一管理模型、开发方式、数据连接、数据保存和隐私状态 |

## 内置能力

当前能力页提供 16 项能力：

1. 做 PPT
2. 写正式文档
3. 深度研究
4. 查港股资料
5. 梳理复杂问题
6. 设计产品界面
7. 整理会议纪要
8. 翻译文字
9. 语音转写
10. 文字润色
11. 做网页报告
12. 比较方案
13. 推进商务合作
14. 模拟市场机会
15. 生成新能力
16. 开发项目（指定本地项目文件夹后，可选择只读检查或开发并验证；交付项目修改、可运行结果和验证记录）

开发入口不会要求普通用户使用命令行。默认使用 Pi Agent，也可切换 DeepSeek Harness、Kilo Code、OpenCode 或 Codex；五种引擎共用项目隔离、验证和修改确认流程。选择“需要时安装依赖”后，只会根据项目已有标志执行确定的项目级命令：Node 锁文件、Python 虚拟环境、`.NET restore` 或 `cargo fetch --locked`。不做全局安装，不接受模型自由拼接安装命令，并为每一步保留回执。

“设计产品界面”的 HTML 结果包含可编辑设计画布：界面名称、目的、主要操作、内容区、状态和四个颜色令牌都可调整，并可切换桌面、平板和手机预览；这些调整进入工作台自动保存与版本恢复。

一次能力执行会同时登记为任务和结果。运行状态与结果送达分开保存；浏览器未确认收到时会在刷新或重启后继续投递。继续处理同一成果时沿用原任务并形成连续版本；失败会保留原因和重试入口。一次任务也可以在工作页转为每日或按使用频率重复执行。

工作空间不是开始任务的前置步骤。用户可以先直接开始；当同一件事出现多个任务时，再创建空间，并在新建或编辑任务时选择归入。空间归档不会删除其中的任务和结果。

资料库支持文字笔记、文本文件和网页链接，归档后可以恢复。任务最多明确选择 8 份资料；未选择的资料不会被默认注入模型上下文。自动化页只是已设置频率任务的集中视图，仍使用同一套持久任务和运行记录。协作页不要求用户配置专家，小丑鱼会根据能力类型和本次任务内容重新选择专业检查，并负责最终交付。

### 专家协作

- 专家不是固定聊天角色，而是带有职责、工具方向、执行流程、交付物和复核标准的内部执行单元；
- 当前专业覆盖研究核验、文档编辑、演示设计、数据分析、项目推进、流程自动化、安全隐私、合同风险、视觉分析，以及产品、工程、商业和决策等领域；
- 开发任务中的工程专家会在用户选定的项目范围内进行只读检查，最终修改仍由小丑鱼统一执行；
- 研究专家可以使用已配置的来源工具，工具不可用时必须明确降级，不能把宣传简介当成真实验证；
- 专家任务不读取其他对话或角色的历史记忆；最终交付只使用用户偏好，并同时接收专家产物的提炼摘要和完整原文；
- 普通界面只显示执行了哪些专业检查，不展示专家市场、内部名称或配置来源。

## 文件工作台

- 读取常见 Word、PowerPoint、Excel、OpenDocument、RTF、EPUB、CSV、PDF、TXT 和 Markdown 格式；
- **上传后生成结构化可编辑副本**（`structured-document.ts`、`office-to-markdown.ts`）：Word 的标题层级、
  列表和表格，PowerPoint 的每页文字、表格和讲者备注，Excel 的每个工作表，
  都会转成对应的 Markdown 结构；
- 每次转换返回结构变化与已知限制清单，界面逐条显示；扫描版 PDF 暂不提供 OCR；
- 原文件完整保留在会话与本机存储中，可下载、可在“原文件”页签查看原版式，
  也可用 Windows 已关联的桌面应用打开；**不会被 Markdown 写回**；
- 写回原文件只对 TXT 和 Markdown 开放，写回前检查原文件是否已被其他程序修改；
- 能力标注见 `office-capabilities.ts`：TXT/Markdown 可直接编辑，其余导入格式均先转换；
- 编辑和 AI 处理都留在文件页；
- 任务和能力结果可直接建立本机工作副本继续编辑；
- 支持版本记录与恢复；
- 导出 DOCX、PDF、PPTX、XLSX、HTML 和 Markdown，产出的是新文件。
- 20 份脱敏日常 DOCX 已通过结构回读并由本机 Microsoft Word 逐份打开；复杂批注、跨节页眉页脚、浮动对象、公式和图表仍由原文件或桌面 Office 保真承接。

## 扩展与连接器

- 六类连接器统一显示真实状态：本地文件、浏览器、GitHub、邮箱、日历和企业文档；
- 本地文件为内置连接，其余连接只有在模型能力或已安装扩展真实可用时才显示“已连接”；
- 扩展支持安装前权限预览、启用、更新、停用、恢复上一版本和卸载；
- 新版本扩大文件、网络、命令、工具或模型权限时必须重新确认。

## 记忆行为

### 任务线程

- 用户消息进入用户命名空间；
- 每个任务保留独立会话上下文，切换任务不会混入其他线程；
- 直接聊聊、完成任务和学习辅导使用各自合适的执行与记忆范围，但界面不暴露内部角色；
- 原始归档与分类记忆分开保存，普通记忆页不展示原始归档；
- 反思、事实失效和领域路由由统一记忆配置开启。

### 能力与文件

- 能力任务统一由小丑鱼接收和交付；专家可以执行受限检查并生成内部产物，但不能代替小丑鱼确认权限、改变长期任务或直接面向用户交付；
- 能力页可选择 **使用我的习惯** 或关闭偏好召回；
- 任务记录会显示本次实际采用的习惯；
- 已完成结果可连同完整原文和提要继续交给另一项能力；
- 开发项目只访问用户明确填写的文件夹，不读取密钥，不删除文件，也不执行推送、发布或部署；
- 文件页的 AI 处理使用偏好召回；
- 偏好召回只查 **procedural** 与 **personal_semantic**；
- 先取最多 12 个候选，再筛选与习惯、文笔、排版或格式相关的最多 6 项；
- 当前请求仍是任务主指令。

### 用户控制

- 记忆页可以明确写入一条全局习惯；
- 可以忘记单条非归档记忆；
- 原始归档受保护，不会被单条忘记或分类清理删除；

## 模型和网络边界

预设服务商包括智谱 GLM、OpenAI、Anthropic Claude、DeepSeek、通义千问、MiniMax 和自定义服务。

- 调用模型时，任务内容和必要上下文会发送给所选服务商；新对话首次发送后还会用日常轻量模型生成短标题；
- 标题生成不调用工具、不写入长期记忆；模型不可用时使用本地规则命名；
- 使用已配置的联网搜索、公开来源或 X 连接器时会访问对应网络服务；未配置的连接器不能视为实时数据源；
- Windows 保存的模型 Key 使用当前用户的 DPAPI 加密；
- 接口与日志不应返回完整密钥；
- 工具、MCP 和 Agent App 按清单、权限和沙箱边界执行。

## 本地或自托管保存

默认是纯本地模式。需要服务器备份时，在 **设置 → 数据保存** 中选择“本地使用 + 自托管服务器同步”。客户端使用 AES-256-GCM 加密快照；同步服务只收到密文。SQLite 写前日志会先完成检查点，再生成快照；DPAPI 密钥文件、日志、缓存和临时文件不会上传。

在仓库根目录启动本机 Docker 服务：

~~~powershell
$env:CLOWNFISH_SYNC_TOKEN="请替换为至少24位随机令牌"
docker compose up -d --build
~~~

然后填写 `http://127.0.0.1:8799`。远程地址必须使用 HTTPS，建议在同步容器前配置反向代理和证书。首次使用先“测试连接”，再“立即备份”；恢复会在重启应用后生效。

同步服务器使用 `If-Match` 版本校验防止另一台设备的更新被静默覆盖。冲突时先恢复最新服务器快照，再重新备份。

旧版数据目录仅在新目录不存在时自动沿用。

## Windows 便携客户端

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File examples\companion\client\Build-Clownfish.ps1
~~~

构建脚本会下载并校验：

- Microsoft WebView2 SDK；
- Node 26.5.0 沙箱运行时；
- Python 3.14.6 嵌入式运行时。

输出目录：

~~~text
examples\companion\client\dist\portable\小丑鱼
~~~

用户数据默认不在程序目录。分享便携包前仍应检查是否误带 **~/.clownfish** 或自定义数据目录。
