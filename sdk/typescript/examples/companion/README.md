# 小丑鱼本机应用

统一发布版本：**0.7.6**（桌面壳、产品清单和 TypeScript 包一致）

记忆核心：**Nemos Memory 0.7.5-alpha.18**

文档复核：**2026-09-25**

小丑鱼是本机优先的个人助理与任务执行应用。网页、Windows 客户端和后台任务共用同一份本机数据；目标、事项、任务、能力、文件和自动化之间共享上下文与产物编号。

## 启动

当前版本的任务工作区支持自动选择 Bot、手动指定、独立完成和自主组织文字协作。自主协作在任务内生成执行计划，显示每一步状态，并使用 5 或 8 次调用预算统一约束规划、执行和重试；工具与长期记忆默认关闭。

技能库（`/skills`）内含随应用发布的原生适配规则模板。可查看完整规则与能力边界，修改名称、规则和启用状态；保存规则不调用模型，任务才调用已配置的模型。这些模板是随应用发布的本地目录，不自动下载第三方脚本或同步第三方账号。深度研究与核验会检索、分级并复核来源；材料梳理只处理本次已经提供的材料，两者互补而不互相替代。

`/bots?view=market` 是为将来的官方市场预留的入口，目前为空，不代表已接入任何在线服务；若将来开放，安装前会展示来源、版本、权限、依赖和将创建的本机内容。

在 `sdk/typescript` 目录执行：

```powershell
npm install
npm run companion
```

打开 <http://localhost:8787>。

| 环境变量 | 作用 |
| --- | --- |
| `PORT` | 修改本机服务端口，默认 8787 |
| `CLOWNFISH_HOME` | 修改应用数据目录，默认 `~/.clownfish` |
| `COMPANION_USER` | 指定本机用户命名空间；部署时必须由可信身份映射 |

服务只监听回环地址，并校验 Host、Origin 与同源浏览器请求。

## 页面与用户流程

| 路径 | 页面 | 主要用途 |
| --- | --- | --- |
| `/overview` | 总览 | 动态、钉住的构件、进行中的事项、近期成果和记忆入口 |
| `/` | 助理 | 小丑鱼与分工助理、对话历史、三种工作方式、快捷回复和右侧活动栏 |
| `/pantheon` | 万神殿 | 多视角立论、质询、回应、收束与私有思维库 |
| `/matters` | 事项 | 目标（`?view=goals`）、持续推进的事项、下一步、提醒与关联成果 |
| `/bots?view=tasks` | 任务 | 新建、搜索、附件、运行状态、项目和自动化入口 |
| `/capabilities` | 能力 | 自动选择或直接启动专门能力 |
| `/artifacts` | 文件 | 生成成果、参考资料、打开与编辑办公文件 |
| `/memory` | 记忆 | 已记住内容和待确认的学习提议 |
| `/skills` | 技能库 | 为你想的点子；查看、编辑、启用本地工作方法 |
| `/automations` | 自动化 | 管理重复任务、暂停、编辑和立即运行 |
| `/settings` | 设置 | 模型、连接器、数据保存、隐私，以及提醒与后台（免打扰、想听 / 别提、动态定时、帮我盯着） |

`/spaces`、`/collaboration`、`/resources`、`/office` 和 `/runs` 仍作为对应工作区的子视图或兼容入口。

首次使用时，在 **设置 → 模型与服务** 填写 OpenAI 和 / 或智谱 BigModel Key。一个 Key 可以先用，两个可以互补；系统自动完成加密保存、推荐筛选、最小验证、启用与能力默认分配。验证会发起真实合成请求并可能产生少量费用。当前 OpenAI 已接入文字、看图、语音识别、语音合成和图像生成，智谱已接入文字；视频和其他智谱媒体能力仍未接入。其他厂商、兼容服务和手工覆盖保留在高级设置。

任务首次发送后自动生成短标题；模型不可用时使用本地规则命名。

## 任务、能力和交接

任务支持直接聊聊、完成任务和学习辅导。小丑鱼是唯一面向用户的统筹入口；专家与教学策略在后台按任务动态选择。

当前能力页提供 17 项能力，覆盖研究、核验、办公文档、会议纪要、文字润色、演示、产品设计、市场简报、方案比较、商务推进、市场机会、选题评估、短视频脚本和扩展构建；OCR、文档转换、信息源发现等内部辅助能力可被聊天、文件或运行时调用，不单独占据能力首页。

一次执行同时登记任务、运行和产物。能力交接包包含：

- 用户原始文字和完整对话原文；
- 去重后的上下文提要；
- 附件及统一文件编号；
- 已有决定、上一步产物和内容指纹；
- 来源、接收和结果回执。

失败任务保留原因和重试入口。运行完成与送达确认分开保存，服务重启后仍可继续投递。

## 助理、目标与主动提醒

**人设**：小丑鱼的名字、回复长度和人设在“助理 → 活动栏 → 身份 → 助手设定”中编辑，聊天与办事共用同一份设定和同一段说话方式；只保存与默认不同的项。回复结尾单独一行 `【选项】A｜B` 会被渲染成快捷回复按钮，存进对话记录前会去掉这一行。

**活动栏**：助理页右侧四个页签——动态、批准、即将到来、身份。结论只取记录的状态（完成、没完成、结果待核对、已完成但未送达），不使用模型写的摘要。

**目标**：从 `/matters?view=goals` 选类别开一段目标对话；小丑鱼经审批调用 `goal_save` 记下口径、计划、期限与子目标，用 `goal_log_progress` 记进展并可附势头判断。每个目标绑定一条聊天线程；定期对进度到点后由服务端标成待对，聊天页每分钟取一次并发一条固定文案（不调用模型）。事项与目标的写入工具都需要审批。

**动态**：`/overview` 顶部。生成时先定最多 3 个搜索词联网搜索，再写最多 5 条；新消息必须引用本次搜到的来源（只收 http 链接），和最近发过的重复不收，没有值得写的就记一句“这次没有值得收录的新内容”。口味只来自喜欢、讨论和不感兴趣（带理由）。可在设置里开启每天定时生成：错过当天会在打开时补一次，不补前一天。

**点子**：`/skills` 顶部。按目标、事项、偏好生成最多 5 个“我能帮你做的事”，只提现在能做到的交付类型（小工具、定时任务、目标、报告、规则），读邮件、下单订票等未接通的内容在校验时丢弃；可挂到相关目标上；两周后下架。

**帮我盯着**：设置 · 提醒与后台。最多 5 件、间隔 1–24 小时、每天最多 48 次检查；没有联网搜索时不运行。每次对照“上次看到”判断，有新变化且有来源才在聊天里提醒；来源时间不明时会写明。

**免打扰与想听 / 别提**：免打扰时段内托盘不弹通知，也不把这批标成已提醒；“想听 / 别提”在写动态、想点子前都会读入，“别提”的话题不搜、不写。

## 构件与产物沙箱

聊天里说“做一个能勾选的清单”“弄个番茄钟”等会走 HTML 能力，按构件约定写单文件、不联网的交互页面，直接嵌在回复里。页面状态经宿主页代存到本机（`/api/capabilities/widget/state`），页面里的 `localStorage` 也会被桥接到这份本机状态；可钉到总览（`/api/capabilities/widget/pin`）。

HTML 产物的预览与内联打开都带 `Content-Security-Policy: sandbox`（不含 `allow-same-origin`）并禁止向外请求：页面脚本可以运行，但没有应用的同源身份，发往 `/api/*` 的请求会被本机同源检查拒绝。

交付前自测：用本机 Edge / Chrome 无头打开注入同一份桥接脚本的页面，断网，点击最多 8 个控件，收集脚本异常、控制台错误和被拦截的外部资源；弹框自动确认并记录，点击时页面刷新会注明。本机没有浏览器时记为“没做自测”；页面没写到 `</html>`（输出被截断）判为不通过。从聊天发起的交付物输出上限至少按“深入”档。

## 文件工作台

### 读取和编辑

- 读取 DOCX、PPTX、XLSX、PDF、ODT/ODS/ODP、RTF、EPUB、CSV、TXT 和 Markdown；
- 对话附件另支持 mp4/mov/webm/mkv/avi 与 mp3/m4a/wav/aac/ogg/flac：本机 ffmpeg 先抽关键帧并转出音轨，再按已接入的视觉与语音识别模型逐帧描述、转写，模型只读到这份结构化文字；未接入的部分在报告里明确标出，不推测画面或台词。表格类附件的每列统计也由本机代码算出后随材料交给模型；
- Word 保留可转换的标题、段落、空行、连续空格、缩进、编号、表格和对齐；
- PDF 通过 `@firecrawl/anydoc` 转为 Markdown 工作副本；
- PowerPoint 按页提取文字、表格和讲者备注；
- Excel 按工作表转换为结构化表格；
- TXT 与 Markdown 可在明确授权后冲突安全地写回原文件；
- 其他格式只编辑副本，不改写原件。

### 保存和导出

- 工作副本自动保存并使用版本号防止旧窗口覆盖新内容；
- 支持版本比较、恢复、删除到垃圾桶和恢复；
- 原文件始终可下载或交给系统关联应用打开；
- 导出 DOCX、PDF、PPTX、XLSX、HTML 和 Markdown 时生成新文件；
- 所有导出先经过对应结构检查。

复杂浮动对象、公式、图表、批注、跨节页眉页脚、演示母版和电子表格公式不承诺无损转换。

## 记忆和数据边界

记忆由外部 `@nemos/sdk` 提供。用户事实、角色自身内容、任务线程和专家执行上下文分别保存。能力可以只召回少量交付偏好，也可以关闭偏好记忆；当前任务要求始终优先。

默认数据目录：

```text
~/.clownfish
```

主要数据包括：

```text
companion.db
llm-key.dpapi.json
tool-settings.dpapi.json
agent-runs.json
agent-jobs.json
agent-approvals.json
personal-work.db      # 事项、目标、学习提议
feed.json             # 动态
ideas.json            # 点子
watch.json            # 帮我盯着
proactive.json        # 免打扰、想听 / 别提、动态定时
personas.json         # 助手设定中与默认不同的项
capabilities/         # 能力、任务、产物；widget-state.json 保存构件状态与钉住
backups/
logs/
```

Windows 模型密钥与同步凭证使用当前用户 DPAPI 加密。日志对常见凭证字段脱敏，但用户仍不应把密钥写入任务正文或项目文件。

## 本地和自托管保存

默认只使用本地数据。需要备份或多设备转移时，可以连接仓库根目录的 Docker 同步服务：

```powershell
$env:CLOWNFISH_SYNC_TOKEN="请替换为至少24位随机令牌"
docker compose up -d --build
```

客户端先使用 AES-256-GCM 加密快照，服务器只保存密文。SQLite 会在快照前完成检查点；DPAPI 文件、日志、缓存和临时文件不会上传。本机可使用 `http://127.0.0.1:8799`，远程地址必须使用 HTTPS。恢复先暂存，重启应用后生效。

## Windows 便携客户端

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File examples\companion\client\Build-Clownfish.ps1
```

输出目录：

```text
examples\companion\client\dist\portable\小丑鱼
```

用户数据默认不进入程序目录。分享便携包前仍应检查是否误带 `~/.clownfish` 或自定义数据目录。

关闭窗口可缩到托盘继续运行。托盘菜单的“开机自动启动”会在当前用户的启动项登记本程序并带 `--background`：开机后直接在托盘运行、不弹窗口；程序移动位置后旧登记不再算作开启。托盘通知轮询 `/api/personal-work/reminder-summary`，汇总事项跟进、目标对进度与盯着的事，免打扰时段内不弹。
